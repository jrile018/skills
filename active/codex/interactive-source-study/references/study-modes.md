# Source study modes

Choose the smallest mode that matches the user's goal. Combine modes only when they serve distinct needs.

## Orientation

Use when the user is starting a source.

- State the central question, thesis, structure, and prerequisites.
- Identify the few terms needed before close reading.
- Note which sections deserve the most attention.

## Guided close reading

Use for a difficult passage, equation, figure, or argument.

- Paraphrase one unit at a time.
- Connect each explanation to a precise source location.
- Surface hidden premises, referents, units, and transitions.
- Ask a short comprehension question before moving on when tutoring.

## Concept map

Use when relationships are harder to understand linearly.

- Represent claims, evidence, mechanisms, dependencies, and objections as distinct node types.
- Avoid adding causal edges that the source does not support.
- Label the map as an interpretation and include source locations for central edges.

## Critical reading

Use when the user asks whether the source is convincing.

- Separate the thesis, evidence, reasoning, assumptions, and omitted alternatives.
- Test whether evidence supports the strength and scope of the conclusion.
- Distinguish an internal critique from external fact-checking.

## Retention and transfer

Use when the user wants to remember or apply the material.

- Generate retrieval questions before answers.
- Mix definitions, explanations, comparisons, and novel applications.
- Revisit misconceptions revealed by answers.
- Prefer a small set of high-value prompts over exhaustive flashcards.

## Source comparison

Use for two or more supplied works.

- Compare the question, definitions, assumptions, evidence, and conclusion.
- Do not force agreement or symmetric treatment when the sources have different aims.
- Identify genuine contradictions separately from differences in scope or terminology.
