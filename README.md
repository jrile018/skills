# Skills Portfolio

Private, reproducible inventory of the skills available to Codex on this workstation.

This repository is organized by responsibility:

| Layer | Purpose | Edit policy |
| --- | --- | --- |
| `active/agents/` | Self-contained snapshots of directly installed shared-agent skills | Generated by sync |
| `active/codex/` | Self-contained snapshots of directly installed Codex skills | Generated by sync |
| `managed/codex-system/` | Current Codex system skills | Generated by sync |
| `managed/codex-plugins/` | Current versioned plugin skills | Generated by sync |
| `owned/` | Local compatibility overlays and intentionally maintained skills | Edit here |

`catalog.json` is the searchable inventory, including origin commit and dirty-state metadata when a directly installed skill comes from a Git checkout. `manifest.json` records the size and SHA-256 digest of every portfolio file. `profiles.json` groups skills by practical workflow without changing their trigger rules or permissions.

The owned `skill-router` uses those exact-path profiles when a request is ambiguous or spans domains. It selects one primary skill and a minimal set of supporting skills instead of loading the full catalog.

The original 2026-09-26 archive remains recoverable at Git tag `snapshot-2026-09-26`. Historical Claude and superseded plugin copies were removed from the current tree to prevent stale duplicates from obscuring the live setup.

## Maintain

```bash
python3 scripts/sync_skills.py
python3 scripts/validate_repository.py
python3 -m unittest discover -s tests -v
```

Run sync after installing, removing, or updating a skill or plugin. It follows top-level installed-skill symlinks so source-repository skills—such as the Ingenius skills—are captured as standalone copies. It refuses nested symlinks that escape a skill root and excludes Git metadata, dependencies, virtual environments, caches, `.env` files, and OS temporary files.

Validation runs the bundled current Codex validator against every catalog entry. `validator-exceptions.json` records five narrow upstream incompatibilities; validation fails if a new incompatibility appears or an exception becomes stale.

## Evaluation baselines

Portfolio-wide external evaluations live under `evaluations/`. The current NVIDIA SkillEvaluator baseline is [`evaluations/skillevaluator-2026-09-30-quality/README.md`](evaluations/skillevaluator-2026-09-30-quality/README.md). Its aggregate JSON preserves every score and finding; per-skill raw renderer output is intentionally ignored because it duplicates that data and embeds workstation-local paths.

See [`docs/USAGE.md`](docs/USAGE.md) for the recommended profiles and day-to-day workflow.
